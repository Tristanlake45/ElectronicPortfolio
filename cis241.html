CIS241 - Secure Banking Web Application

Documentation for a dynamic PHP/MySQL banking application with secure user authentication and data handling.

Project Description

This project is a secure banking web application developed using PHP and a MySQL database. The system allows users to create accounts, log in securely, and access sensitive banking information such as account balances and stored data.

A major focus of this project was implementing secure handling of user credentials and database interactions. The application demonstrates how server-side logic can safely retrieve and manage user data while preventing common vulnerabilities such as SQL injection.

Key Features

  • User authentication system (login/logout)
  • Secure database queries using prepared statements
  • Session-based user tracking
  • Dynamic content loaded from MySQL database
  • Structured CRUD-style data handling

Technologies Used

  • PHP
  • MySQL
  • HTML/CSS
  • JavaScript

Sample Code

This example demonstrates a secure login query using prepared statements to prevent SQL injection. 

$stmt = $conn->prepare("SELECT * FROM users WHERE username = ? AND password = ?");
$stmt->bind_param("ss", $username, $password);
$stmt->execute();
$result = $stmt->get_result();
