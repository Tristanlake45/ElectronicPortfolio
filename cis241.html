CIS241 Dynamic Project

Secure Banking Web Application

A database-backed secure banking application that demonstrates login handling, protected account data, server-side validation, and structured data access.

Project Description

This project simulates a secure online banking system. The application stores user login and banking information in a database and uses server-side logic to retrieve account data only after a user has authenticated.

The purpose of this project was to practice building a dynamic database-driven application with secure login flow, protected user sessions, and organized backend code. It shows how a web application can separate user interface, database access, authentication, and account functionality.

Sample Code

This sample demonstrates the expected pattern for securely querying login data with prepared statements instead of directly placing user input into a SQL query. 

$stmt = $conn->prepare("SELECT * FROM users WHERE username = ?");
$stmt->bind_param("s", $username);
$stmt->execute();

$result = $stmt->get_result();
$user = $result->fetch_assoc();

if ($user && password_verify($password, $user["password_hash"])) {
    $_SESSION["user_id"] = $user["id"];
    header("Location: account.php");
    exit;
}
