CIS296 - SportsPro Technical Support

Documentation for my advanced C# / ASP.NET Core MVC project.

Project Description

SportsPro Technical Support is an ASP.NET Core MVC web application designed to manage sports software support information. The application includes administrative pages for managing products, technicians, customers, incidents, and registrations.

This project demonstrates MVC structure, model binding, view models, database-driven pages, navigation, and Bootstrap-based layout. The screenshot below shows the main admin dashboard with links to the major management sections.

Technologies Used

  • C#
  • ASP.NET Core MVC
  • Entity Framework Core
  • Bootstrap
  • Razor Views
  • SQL Server or SQLite

Sample Code

This view model is used when adding or editing incidents. It packages the incident data together with lists of customers, products, and technicians so the Razor view can populate dropdown menus. 

namespace SportsPro.ViewModels
{
    public class IncidentAddEditViewModel
    {
        public List<Customer> Customers { get; set; } = new List<Customer>();
        public List<Product> Products { get; set; } = new List<Product>();
        public List<Technician> Technicians { get; set; } = new List<Technician>();

        public Incident Incident { get; set; } = new Incident();

        // "Add" or "Edit"
        public string Action { get; set; } = "Add";
    }
}
