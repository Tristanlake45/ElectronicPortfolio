Project Description

This project is a responsive website built for Kids Against Hunger Sioux Falls. The goal was to create a modern, visually engaging site that clearly communicates the organization’s mission while encouraging volunteer participation and donations.

The site focuses on clean layout, strong visual hierarchy, and mobile responsiveness. It includes dynamic UI elements such as a responsive navigation menu and optimized layout for both desktop and mobile devices.

Technologies Used

  • HTML
  • CSS
  • JavaScript
  • Responsive Design
